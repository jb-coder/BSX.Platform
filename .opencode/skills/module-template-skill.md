# BSX Platform Module Template Skill

## Purpose

This document defines the standard structure for every module within BSX Platform.

All modules must follow this structure to ensure consistency, maintainability, scalability, and predictable navigation throughout the codebase.

---

# Module Philosophy

Each module represents a business capability.

Examples:

- Identity
- CRM
- Inventory
- Sales
- Purchasing
- Accounting

Modules must be self-contained and independently evolvable.
