# BSX Platform GitFlow Strategy

## Main Branches

main

develop

---

## Feature Branches

Naming:

feature/customer-management

feature/crm-module

feature/inventory-module

---

## Hotfix Branches

hotfix/login-error

hotfix/security-fix

---

## Release Branches

release/v0.1.0

release/v1.0.0

---

## Commit Messages

Format:

type(scope): description

Examples:

feat(crm): add customer creation

feat(identity): implement JWT authentication

fix(inventory): prevent negative stock

refactor(sales): simplify order aggregate

docs(architecture): update module diagram

test(crm): add customer integration tests

---

## Versioning

Semantic Versioning.

Major.Minor.Patch

Example:

0.1.0

0.2.0

1.0.0

1.1.0

2.0.0
