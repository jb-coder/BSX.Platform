# BSX Platform Design System Skill

## Purpose

Defines the visual identity of BSX Platform.

The product must feel modern, premium and enterprise ready.

Inspiration:

- Linear
- Stripe
- Notion
- Vercel
- Raycast

Never imitate traditional ERP systems.

---

# Design Philosophy

Modern.
Minimal.
Professional.

Focus on clarity.

Avoid clutter.

---

# Theme Strategy

Dark First.

Primary experience is dark mode.

Light mode is secondary.

---

# Layout Principles

Use whitespace aggressively.

Avoid dense screens.

Content should breathe.

---

# Navigation

Collapse sidebar.

Global search.

Command palette.

Keyboard-first interactions.

Required shortcut:

CTRL + K

---

# Dashboard Principles

Dashboards must create a wow effect.

Allow:

- Widgets
- Drag and Drop
- Personalization

Every dashboard should answer:

"What matters right now?"

---

# Cards

Cards are the primary UI element.

Requirements:

- Rounded corners
- Soft shadows
- Hover feedback
- Consistent spacing

---

# Tables

Avoid traditional ERP tables.

Preferred:

- Avatars
- Status badges
- Rich metadata
- Inline actions

Tables should feel closer to Notion than SAP.

---

# Animations

Subtle.

150-300ms.

Never distract users.

Animations should communicate state changes only.

---

# Accessibility

Keyboard navigation required.

Semantic HTML required.

Color contrast must remain accessible.

Accessibility is not optional.

---

# Component Reuse

Every reusable element must become a component.

Avoid duplicated UI implementations.

Consistency is more important than creativity.
